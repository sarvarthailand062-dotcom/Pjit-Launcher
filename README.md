# PJIT Launcher

A simple Android launcher project.

Features:
- Add installed apps/games from a launcher list.
- Display selected games.
- Launch a selected game.

Build:
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Build > Build APK(s).

This project intentionally does not inject code, modify memory, bypass anti-cheat, or alter third-party games.
For your own games, enemy-location and aim-assist mechanics should be implemented inside the game's source/project.
